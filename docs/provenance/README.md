# AeroLink source provenance

This directory preserves the original supplied source material and the trace explaining how its ideas were dispositioned into AeroLink's product definition.

- [`SOURCE_MATERIAL_TRACEABILITY.md`](SOURCE_MATERIAL_TRACEABILITY.md) — source-intent disposition map.
- [`original-inputs/`](original-inputs/) — byte-preserved original Word inputs. These are historical inputs, not current product specifications.

The original-input files were moved here without changing their Git blob contents. Current product truth is [`../../PROJECT_STATE.md`](../../PROJECT_STATE.md); accepted product decisions are [`../../DECISIONS_AND_OPEN_QUESTIONS.md`](../../DECISIONS_AND_OPEN_QUESTIONS.md).

Do not edit an original input merely to make it agree with today's product. Its value is provenance: what was supplied at the beginning and how that intent was subsequently accepted, corrected, deferred, or excluded.
